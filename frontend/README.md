# 🌾 Krishi Rakshak AI - Frontend Module

This directory contains the user interface and presentation layer for Krishi Rakshak AI.

## Files
- `app.py`: Streamlit-based web dashboard with camera capture, file upload, confidence progress gauges, multilingual UI, agro-weather cards, and farmer scan history analytics.
- `translations.json`: Complete dictionary for English and Hindi (देवनागरी) UI translation.
- `run_frontend.bat`: Double-clickable Windows batch launcher for the Streamlit app.

## Running Frontend Directly
```powershell
streamlit run app.py
```
Or double-click `run_frontend.bat`.
